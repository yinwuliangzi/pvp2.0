# 手机悬浮窗 · 完整用法

## 先说结论

| 平台 | 能不能盖在游戏上 | 办法 |
|---|---|---|
| **Android** | ✅ 能 | 装 `喵喵洛克PVP助手.apk`（已有成品） |
| **iOS / iPadOS** | ❌ 不能 | 系统不允许，只能用分屏 / 第二台设备 |

iOS 不是网页没写好，而是**系统层面禁止**第三方 App 覆盖另一个 App。任何声称能做的方案都不靠谱。

---

## 一、Android：悬浮窗（推荐）

### 1. 安装

1. 把 `喵喵洛克PVP助手.apk` 传到手机
2. 点击安装，允许「安装未知来源应用」
3. 打开 App

### 2. 授权

打开后会要权限，**第一次一定要给全**：

| 权限 | 不给会怎样 |
|---|---|
| **悬浮窗 / 显示在其他应用上层** | 悬浮窗完全不出现 |
| 通知（Android 13+） | 不显示常驻通知，功能仍可用 |
| 读取图片（识图要用） | 「识」键读不到截图 |

> 权限入口：设置 → 应用 → 喵喵洛克PVP助手 → 权限

### 3. 启动

回到游戏，屏幕底部出现一条操作栏 = 成功。

## 二、悬浮窗界面说明

### 默认状态

**只有屏幕底部一条操作栏**，游戏画面完全不被遮挡。

```text
出招  聚能  换人  道具 | 队  识  关  页面 | 出招  聚能  换人  道具 | 状态
└────── 我方 ──────┘  └── 功能键 ──┘  └────── 对手 ──────┘
```

### 逐项说明

| 键 | 作用 |
|---|---|
| **出招 / 聚能 / 换人 / 道具** | 前 4 个是我方，后 4 个是对手。按下后状态栏显示「我·出招」这类反馈 |
| **队** | 打开计算器 |
| **识** | 识图（读血量 / 战报） |
| **关** | 关闭悬浮窗 |
| **页面** | 展开/收起完整 deck（含反向推断面板） |

### 展开页面后

deck 会盖住屏幕中上部，底部操作栏仍在。

- **收起**：点「收起」或再点「页面」
- deck 里的反推面板可以上下滑动（右侧金色细条是滚动条）

### 关闭

- 点「关」
- 或通知栏里停掉悬浮 HUD

## 三、三种手机用法对比

| 方式 | 怎么开 | 优点 | 缺点 |
|---|---|---|---|
| **悬浮窗 APK** | 装 APK + 授权 | 真覆盖，不切屏 | 仅 Android |
| **全屏录入** | 浏览器开 `calculator.html?hud=1` | 大按钮，点招即记 | 要切屏 |
| **系统分屏** | 加 `&compact=1` | 边看边记 | 占半屏 |

### 全屏录入模式

```text
calculator.html?hud=1
```

得到全屏大按钮界面，适合手机竖屏单手操作。

### 紧凑模式

```text
calculator.html?hud=1&compact=1
```

- 目标 360×500 内完成「选招 → 记录」
- 窗口高度 < 620 时自动进入紧凑模式
- 也可以点顶部「紧凑」手动切换
- 「记录本回合」按钮是 sticky 的，滚动时始终可见

### 分屏操作（按品牌）

| 品牌 | 操作 |
|---|---|
| 三星 | 最近任务 → 长按应用 → 弹出视图 / 分屏 |
| 小米 / Redmi | 最近任务 → 长按 → 小窗 / 分屏 |
| OPPO / vivo / 荣耀 | 最近任务 → 应用浮窗 / 分屏 |

浏览器建议 Chrome / Edge / 三星浏览器。

## 四、iOS 怎么办

### 能用的

1. **添加到主屏幕（PWA）**
   Safari 打开站点 → 分享 → 添加到主屏幕。
   会以独立窗口运行，少一层地址栏。
   > 但切回游戏时 HUD 会进后台，**不会浮在游戏上**。

2. **iPad 分屏 / Slide Over**
   游戏一边、Safari 一边。这是「并排」，不是覆盖。

3. **第二台设备**
   游戏在手机，HUD 在另一台设备或电脑上开。
   > 目前没有跨设备实时同步，是独立记录。

### 不推荐

| 方案 | 为什么不行 |
|---|---|
| 画中画（PiP） | 只能浮视频，不能点击输入 |
| 越狱插件 | 需要越狱，普通用户不适用 |
| 录屏/直播叠加 | 只能看，不能操作 |

## 五、常见问题

### 装了但看不到操作栏

1. 悬浮窗权限给了吗？（设置里找「显示在其他应用上层」）
2. 是不是竖屏？横屏才显示
3. 重装 APK 后**权限会重置**，要重新授权

### 操作栏挡住了游戏按钮

- 操作栏很小（29×22dp），贴在屏幕最底部
- 如果游戏底部有关键按钮，按「页面」展开后再收起会重新定位
- 实在冲突就关掉（点「关」），改用全屏录入模式

### 点了没反应

- 确认装的是最新版
- 重装后权限重置会导致悬浮窗行为异常，重新授权一次

### 识图读不到

- 系统相册里**最新一张**截图才会被读
- 截完等 1-2 秒再点「识」
- 检查「读取图片」权限

## 六、技术说明（给想改的人）

APK 的实现方式：

```text
TYPE_APPLICATION_OVERLAY 悬浮窗
  ├─ 底部操作栏：原生 LinearLayout + TextView
  └─ deck 浮层：WebView 加载 assets/battle-deck.html
       （按需创建，点了「页面」才 load，省内存）
```

- 前台服务保证不被杀
- 操作栏用 `FLAG_NOT_FOCUSABLE | FLAG_NOT_TOUCH_MODAL`，只在自己区域接管触摸
- 源码在 `android-screenshot-importer/`，Gradle 直接 build

> 早期文档说「没有编译出 APK，需要自己 Build」—— 那是历史状态，现在已有成品。
