# 抓包自动录入 · 完整教程

从「游戏里打一局」到「计算器自动记下每一回合」。

> 这份文档对照实际代码逐项核对过（rkpp_live_tools.py / relay_cors_proxy.py / calculator.html）。
> 之前版本里的路径、依赖、坏掉的公式标记都已修正。

---

## 0. 它到底做什么

```text
游戏客户端
   │ TCP 加密包
   ▼
rkpp_live_tools.py opencode-server      ← 抓包 + 解密 + 解析成结构化事件
   127.0.0.1:8765 (NDJSON)
   ▼
relay_cors_proxy.py                     ← 补 CORS / Private-Network 头
   127.0.0.1:8766 (HTTP)
   ▼
计算器「接抓包」→ /events               ← 自动填招式、血量、能量，自动记回合
```

三个组件各自解决一个问题：

| 组件 | 作用 | 为什么不能省 |
|---|---|---|
| opencode-server | 读网卡、解密、翻译成事件 | 核心 |
| CORS 代理 | 补跨域头 | 浏览器直连 8765 会被拦 |
| 计算器 | 吃事件、填界面、记回合 | 展示与落库 |

## 1. 环境准备

### 1.1 必需

- **Windows**（抓包依赖 Npcap，Windows 专用）
- **管理员权限**（读网卡必须有）
- **Python 3.10+**
- **Npcap**（见 1.2）
- `rkpp_live_tools.py`（抓包解密工具，放在任意目录）
- `site/tools/relay_cors_proxy.py`（本项目自带）

### 1.2 装 Npcap

1. 下载 Npcap 安装包
2. 安装时**务必勾选** `Install Npcap in WinPcap API-compatible Mode`
3. 其余默认下一步即可

> 不勾兼容模式，Python 的抓包库找不到网卡。

### 1.3 装 Python 依赖

```powershell
pip install scapy
```

**这一步最容易漏**。装了 Npcap 但没装 scapy，运行会直接报：

```text
ModuleNotFoundError: No module named 'scapy'
```

> 如果后面还报别的缺失模块，按报错里的模块名 `pip install` 即可。

## 2. 确认网卡

**管理员 PowerShell**，进到 `rkpp_live_tools.py` 所在目录：

```powershell
python rkpp_live_tools.py --list-ifaces
```

输出里找到你游戏走的那张网卡（有线一般是「以太网」，无线是「WLAN」）。

想省得每次指定，可以设成默认：

```powershell
python rkpp_live_tools.py --set-default-iface "以太网"
```

查看当前默认：

```powershell
python rkpp_live_tools.py --show-default-iface
```

---

## 3. 抓 key（第一次必做）

游戏包是加密的，**必须先抓一个 key** 才能解出来。

```powershell
python rkpp_live_tools.py capture-key
```

- 运行后**进游戏随便打一局**（或重新登录一次）
- 抓到后会自动写出 `key.txt`
- 看到 key 文件生成即可 `Ctrl+C` 停掉

> 已知 key 时也可直接跳过这步，用 `--key` 传入：
> **16 字节 ASCII** 或 **32 位 hex** 两种写法都行。

---

## 4. 启动抓包服务

**管理员 PowerShell**：

```powershell
python rkpp_live_tools.py opencode-server --relay-port 8765
```

看到 `server_mode=normal` 之类的日志就说明起来了。

### 常用参数

| 参数 | 作用 | 默认 |
|---|---|---|
| `--iface "以太网"` | 指定网卡 | 自动监听 |
| `--iface-only` | 只抓指定网卡，不自动扩展 | 关 |
| `--relay-host` | relay 监听地址 | 127.0.0.1 |
| `--relay-port` | relay 端口 | 8765 |
| `--relay-history` | 保留多少条历史事件 | 5000 |
| `--opcode-summary-out out.csv` | 同时导出摘要 CSV | 无 |
| `--server-mode move` | 只提供换人事件（调试用） | normal |
| `--move-csv-out move.csv` | move 模式下的换人 CSV | 无 |
| `--allow-stale-key` | 允许沿用上次 key | 关 |
| `--key <key>` | 直接指定 key | 读 key.txt |

> `--allow-stale-key` 的含义：默认会等本次连接刷新 key；打开这个开关可以用上次保存的 key 立即开始。
> 如果启动后一直没事件，试试加/去掉这个开关。

## 5. 启动 CORS 代理

**另开一个** PowerShell（不需要管理员），工作目录 = 本项目的 `site/tools/`：

```powershell
cd site\tools
python relay_cors_proxy.py
```

正常输出：

```text
[proxy] http://127.0.0.1:8766 -> http://127.0.0.1:8765 (CORS + PNA)
```

### 为什么必须走代理

浏览器的两道限制：

1. **同源策略** —— 页面和 8765 不同源
2. **Private Network Access** —— Chrome 会拦「公网页面访问本机地址」

代理补了三个头解决：

```text
Access-Control-Allow-Origin: *
Access-Control-Allow-Private-Network: true
Cache-Control: no-store
```

### 代理参数

```powershell
python relay_cors_proxy.py --port 8766 --target 127.0.0.1:8765
```

默认值就是这两个，一般不用改。

## 6. 计算器里连上

1. 打开 `calculator.html`
2. 点右上角 **接抓包**
3. **事件地址** 填 `http://127.0.0.1:8766/events`（默认已填好）
4. 两个勾选项：
   - **两边都出招后自动记一回合** —— 推荐勾上
   - **wrappers 顺序是「敌-我」** —— 只有事件顺序反了才勾
5. 点 **连接**

状态栏出现：

```text
已连接，等待事件…
```

下方黑色区域会显示最近一条原始事件 —— **这是确认收到数据最直接的证据**。

---

## 7. 进游戏打一局

抓包模式会自动做这些：

| 抓到什么 | 自动做什么 |
|---|---|
| 你选招 | 填「我方招式」，动作切到「出招」 |
| 对手出招 | 填「敌方招式」 |
| 血量 / 能量变化 | 直接采用服务器值，不再本地重复扣 |
| 两边都出招后静默 900ms | 自动点「记录本回合」 |
| 回合切换 | 对齐一次记录，防止漏记 |

> **不要在抓包模式下再手动点「记录本回合」**，否则会记成两回合。

---

## 8. 抓包 vs 平时，行为差异

| 项目 | 平时 | 抓包模式 |
|---|---|---|
| 能量不够 | 阻止出招 | 不拦，按服务器事件记 |
| 血量 / 能量 | 本地计算扣减 | 用服务器回传值 |
| 记录方式 | 手动点按钮 | 自动 |

想回到手动：点 **断开**。

## 9. 排查

### 9.1 启动就报 ModuleNotFoundError

缺 Python 库。按报错里的名字装：

```powershell
pip install scapy
```

### 9.2 --list-ifaces 看不到网卡

- Npcap 是否装了
- 是否勾了 **WinPcap 兼容模式**
- 是否用**管理员**运行的 PowerShell

### 9.3 连不上：HTTP 404 / Failed to fetch

按顺序查：

1. **两个服务都在跑** —— 8765（opencode-server）+ 8766（proxy），两个窗口都别关
2. **地址是 8766 不是 8765** —— `http://127.0.0.1:8766/events`
3. 页面如果是通过**局域网 IP** 打开的，Private Network 可能拦，换成 `http://localhost:8766/events` 试
4. 防火墙是否拦了 8766

### 9.4 连上了但一直没事件

- 游戏是否真的在跑、是否走了你抓的那张网卡
- `--list-ifaces` 确认网卡名，必要时 `--iface-only --iface "以太网"`
- **key 是否过期** —— 重跑 `capture-key`，或加 `--allow-stale-key` 试
- 是否管理员权限（普通权限抓不到包）
- 黑框里有没有原始事件（有事件说明通了，是解析问题；没事件是抓包问题）

### 9.5 招式名对不上

- 页面会用技能表校验，表里没有的名字直接丢弃
- 顺序错位：勾选/取消 **wrappers 顺序是「敌-我」**
- 如果是新精灵新技能还没进词表，会认不出 —— 这属于数据更新问题

### 9.6 记成了重复回合

- 关掉「两边都出招后自动记一回合」，改手动确认
- 或先 **断开**，把这一局手动补完

## 10. 安全与隐私

- 抓包全程只在 **本机环回地址** 之间传（127.0.0.1 → 127.0.0.1）
- **不上传任何服务器**
- 事件只在你自己的浏览器里解析，存在 localStorage
- 抓包需要读网络包，属于本地工具行为
- 请只在**自己的账号、自己的设备**上使用

---

## 11. 不想抓包？三种替代

| 方式 | 难度 | 适合 |
|---|---|---|
| **战报识别** | 最低 | 打完看战报，点「识」自动读技能名 |
| **截图识别** | 低 | 上传对局截图，读血条与招式 |
| **手动记录** | — | 直接选动作招式，点「记录本回合」 |

> 注意：现在的识别是**本地 ML Kit**，不需要任何 API Key，也不联网。

三种方式可以混用：抓包断了用战报识别补一条，再切回手动。

```powershell
# 1) 装依赖
pip install scapy

# 2) 看网卡
python rkpp_live_tools.py --list-ifaces

# 3) 抓 key（进游戏打一局）
python rkpp_live_tools.py capture-key

# 4) 起抓包服务（管理员，窗口 A）
python rkpp_live_tools.py opencode-server --relay-port 8765

# 5) 起代理（窗口 B）
cd site\tools
python relay_cors_proxy.py

# 6) 计算器 → 接抓包 → http://127.0.0.1:8766/events → 连接
# 7) 进游戏打
```
