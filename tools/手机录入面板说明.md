# 手机录入面板说明

## 什么时候用

不适合装悬浮窗，或只是想边看边记的时候：

| 模式 | 地址 | 适合 |
|---|---|---|
| 全屏录入 | `calculator.html?hud=1` | 手机竖屏单手操作 |
| 紧凑模式 | `calculator.html?hud=1&compact=1` | 系统小窗 / 分屏 |
| 自动判断 | 窗口高度 < 620 自动进入紧凑 | 不用记参数 |

---

## 全屏录入模式

```text
calculator.html?hud=1
```

### 布局

```text
┌──────────────────────────┐
│  我方 · 迪莫       光     │  ← 顶部：双方精灵名
├──────────────────────────┤
│ ┌────────┐ ┌────────┐   │
│ │ 纤维化  │ │ 水炮一击 │   │  ← 技能卡：点一下 = 选中这招
│ │  防御   │ │  356    │   │
│ ├────────┤ ├────────┤   │
│ │ 气泡一击 │ │ 后发制人 │   │
│ └────────┘ └────────┘   │
├──────────────────────────┤
│  出招  聚能  换人  道具    │  ← 动作选择
├──────────────────────────┤
│      [ 记录本回合 ]       │  ← 主按钮（sticky，始终可见）
└──────────────────────────┘
```

### 操作流程

1. 点技能卡选中招式
2. 选动作（出招 / 聚能 / 换人 / 道具）
3. 点「记录本回合」

## 紧凑模式

```text
calculator.html?hud=1&compact=1
```

### 差异

| 项 | 全屏 | 紧凑 |
|---|---|---|
| 目标尺寸 | 全屏 | 360×500 |
| 技能卡 | 2 列大卡 | 2 列小卡 |
| 字体 | 正常 | 缩小一档 |
| 记录按钮 | 底部 | sticky 底部 |

### 自动切换

窗口高度 **< 620px** 时自动进紧凑模式。
也可以点顶部「紧凑」按钮手动切。

### 更窄的屏

宽度 **≤ 340** 时再自动缩一档，320×480 也能完整看到「记录本回合」。

---

## 分屏怎么用

以 Android 为例：

1. 打开浏览器 → 输入 `calculator.html?hud=1&compact=1`
2. 最近任务 → 长按浏览器 → 分屏 / 小窗
3. 另一半打开游戏

不同品牌的入口：

| 品牌 | 操作 |
|---|---|
| 三星 | 最近任务 → 长按应用 → 弹出视图 / 分屏 |
| 小米 / Redmi | 最近任务 → 长按 → 小窗 / 分屏 |
| OPPO / vivo / 荣耀 | 最近任务 → 应用浮窗 / 分屏 |

## 常见问题

### 按钮太小点不准

用全屏录入模式（去掉 `compact=1`），按钮会大很多。

### 「记录本回合」看不到

- 紧凑模式下按钮是 sticky 的，应该始终在底部
- 如果被浏览器地址栏挡住，往下滚一点
- 或把浏览器地址栏收起（设置里可以开「全屏浏览」）

### 数据会不会丢

存在浏览器 localStorage。清缓存 / 换设备会丢，重要记录用「导出记录」。

### 和悬浮窗能一起用吗

可以。悬浮窗是 APK 独立进程，网页是浏览器，各自存各自的数据，互不干扰。
但两边记录不会自动同步。

### 横屏还是竖屏

竖屏为主。横屏下会按宽度重新排版，但技能卡会偏小，建议竖屏用。
