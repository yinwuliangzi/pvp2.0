使用说明

这套工具解决三件事：这一下打多少、还要几发、这回合该想什么。

对战计算器 → 局面速算 →

两个页面分别干什么

对战计算器：选我方/敌方各 6 只，看每一招打多少、几发打倒；记录每回合的动作，自动推进“五段轮次”时间轴。

局面速算：不管阵容，只填当前局面（血量、能量、先手、魔力值），马上给出“还差几次击杀 / 对手还能撑几轮 / 这轮谁先手”。

第一次用，先做这一步：校准系数

公式算出来的是“相对值”，要跟游戏里的真实伤害对一次。

  1. 选好双方精灵、招式
  2. 游戏里打一下，记住实际伤害（比如 200）
  3. 把 200 填进「实测伤害」，点「校准」

校准一次即可，同一套数据后续都准。换了公式版本会需要重校一次。

阅读伤害卡

  • 147（满血 42%）：这一下打掉对方满血的 42%
  • 一击 / 2 发 / 6 发：还需要几发能打倒
  • 本系加成 ×1.25：技能属性和精灵属性相同
  • 特性：威力+50%（先手）：这条特性算进去了
  • 特性未计入：…：这条特性现在算不了，伤害会偏少

记录回合怎么用

  1. 选「我方动作 / 对手动作」（出招、聚能、换人、应对、道具）
  2. 选本回合双方实际用的招式
  3. （可选）贴一条策略标签，比如“低费混合试探”
  4. 点「记录本回合」——伤害、能量、魔力值、状态掉血会一起结算

顶部时间条按 50 回合走，颜色是当前所处的轮次段：信息试探 / 能量压制 / 发育破局 / 兑现斩杀 / 残局收束。

整局存档

「导出记录」会把双方配置 + 全部回合历史存成一个 json 文件；「导入记录」读回来，换台电脑也能接着复盘。

数据从哪来

  • 精灵 550 只、技能 840 条、可学技能表 433 只、立绘 531 张
  • 属性/种族值/特性/血脉/进化链：官方数据文件
  • 状态与印记：官方 buff 表（含触发时机、叠加上限、免疫）
  • 伤害公式：官方引擎结构（37/41 常数、本系 1.25、克制、特性、印记、连击）
已知局限
· 约 10 条“入场/离场/击败/每使用 N 次”类特性算不了，卡片会标黄提示
· 双打只做了目标与群体技能口径，没有做双速先手与集火顺序
· 进化之力没有校验“首领血脉”前置，只做提示
· 各人数据存在自己浏览器里，不会上传，互不影响
