1. 选择你的用法

同一套数据，三种打开方式，按你在哪玩选：

场景用哪个特点
手机边打边看喵喵洛克PVP助手.apk悬浮在游戏上层，不切屏
电脑边打边看电脑版 exe透明置顶 + 全局快捷键
事后复盘 / 研究浏览器开 calculator.html屏幕大，看得全
对战矩阵 → 对局路径 → 胜率估计 → 对战计算器 → 局面速算 →

两个网页分别干什么

对战计算器：配好双方 6 只，看每一招打多少、几发打倒，记录每回合动作，自动推进五段轮次时间轴。

局面速算：不管阵容，只填当前局面（血量、能量、先手、魔力值），马上算出「还差几次击杀 / 对手还能撑几轮 / 这轮谁先手」。

2. 第一次用：先配阵容

  1. 底部有三个页签：我方精灵 / 对战 / 敌方精灵。先把我方 6 个槽位填上。
  2. 点空槽位打开选择器，三种筛选可叠加：
    • 名字搜索 —— 打字直接找
    • 只看 S5·新增 —— 只列新赛季精灵
    • 按属性 —— 18 种属性筛选
  3. 选中后自动带出：属性、种族值、特性、可学技能，并按属性配好 4 招。
  4. 想换招：点技能卡重选。缺副属性的精灵会提示「副属性可能缺」，可在下拉里手动指定。
省时间的小技巧
· 对手阵容不确定时，先只填我方，敌方空着也能算伤害
· 常用阵容配一次即可，页面会自动记住

3. 看懂伤害卡

每张技能卡上就是这一招的完整结论：

147（满血 42%） —— 这一下打掉对方满血的 42%

一击 / 2 发 / 6 发 —— 还需要几发能打倒

本系加成 ×1.25 —— 技能和精灵属性相同

✅ 可击杀 —— 当前血量这一下就能收

能量不够，要聚能 —— 蓝不够，这招这回合放不出来

特性未计入：… —— 这条特性现在算不了，实际伤害会比显示的高

伤害按官方引擎结构算：37/41 常数、本系 ×1.25、属性克制、特性、印记、连击、天气。
没有随机浮动，同一配置每次出同一个数。跟游戏对不上就做第 4 步校准。

4. 校准系数（只做一次）

页面上方有个「系数」，默认 1。校准就是让它对上游戏里的真实伤害。

配好双方→游戏里打一下→记住实测伤害→填进「实测伤害」→点「校准」

例：页面算 380，游戏里实际 200，就填 200 点校准，系数会自动变成约 0.53。

5. 记录一局

  1. 切到「对战」页签
  2. 选我方动作和对手动作：出招 / 聚能 / 换人 / 应对 / 道具
  3. 选双方本回合实际用的招式（「选择技」会多一行分支下拉）
  4. 有倒下或对手被迫聚能，对应下拉里选一下
  5. 点 记录本回合 —— 伤害、能量、魔力、状态掉血、天气、印记一起结算

顶部时间条按 50 回合走，五段颜色：

信息试探 1–4·能量压制 5–10·发育破局 11–16·兑现斩杀 17–24·残局收束 25–50

记错了点「撤回上一回合」，或用「还原到第几回合」整个回退。

6. 手机悬浮窗

安装

  1. 安装 喵喵洛克PVP助手.apk（允许未知来源）
  2. 打开 App → 授予悬浮窗权限；Android 13+ 会再要通知权限（拒绝也能用）
  3. 回到游戏，底部出现操作栏即成功

界面

默认状态：只有屏幕底部一条操作栏，游戏画面完全不被遮挡。

操作栏：出招 聚能 换人 道具 | 队 识 关 页面 | 出招 聚能 换人 道具 | 状态

出招聚能换人道具前半=我方，后半=对手

页面：按一下展开完整 deck（含反推面板），再按或按「收起」还原。

识：一键识别截图（详见第 7 节）。

关：关闭悬浮窗。

三种手机用法对比

方式怎么开适合
悬浮窗装 APK，授权悬浮窗边打边看（推荐）
全屏录入浏览器开 calculator.html?hud=1大按钮，点招即记
系统分屏加 &compact=1360×500 小窗也能用
iOS 没有系统级悬浮窗，任何浏览器或 App 都不能盖在游戏上。
iPhone 可以「分享 → 添加到主屏幕」做全屏 PWA；iPad 可用分屏并排。

7. 战报识别

游戏里打开战报弹窗 → 截图 → 点「识」，自动读出双方技能名、类型、威力、耗能。

打开战报→截图→点「识」→状态栏显示「战报 · 技能A/技能B」

能读到什么

  • 技能名（含「应对！风墙」这类前缀）
  • 类型：攻击 / 防御 / 状态
  • 威力（如 250、420、880）
  • 耗能
  • 效果描述文字

识别后 deck 会弹出战报卡片，并把第一个技能自动填进「敌方技能」下拉。

普通对战截图

不开战报直接点「识」，会读双方血条百分比（按 1200×540 界面比例标定），状态栏显示「血 我80%/敌36%」。

识别不准怎么办
· 取图：系统相册里最新一张截图才会被识别，截完要等 1–2 秒再点
· 技能名有 9KB 词表做模糊匹配，错一个字也能认出来，最可靠
· 威力是启发式提取，偶尔会偏。名字对了就以名字为准
· 真机 UI 改版导致读不准时，把那张截图发出来重新标定

8. 电脑版

启动

解压 喵喵洛克PVP助手-电脑版.zip → 双击 喵喵洛克PVP助手.exe。绿色版，不用装。

界面

和手机一样：默认只有底部操作栏，透明置顶，游戏画面不被遮挡。
鼠标只会在指到按钮/面板时被接管，其余位置点击会穿透到下面的游戏。

快捷键（全局，切到游戏也生效）

键功能
F1显示 / 隐藏整个悬浮层
F2识图
F3页面 展开 / 收起
F4关闭程序
F5打开计算器
F6快捷键说明面板
QWER我方 出招 / 聚能 / 换人 / 道具
UIOP对手 出招 / 聚能 / 换人 / 道具
Esc收起页面
怎么改键

编辑 resources\app\keys.json：

{
  "mine": { "attack": "Q", "charge": "W", "switch": "E", "item": "R" },
  "foe":  { "attack": "U", "charge": "I", "switch": "O", "item": "P" },
  "toggleHud": "F1", "scan": "F2", "page": "F3",
  "close": "F4", "team": "F5", "help": "F6"
}

支持 "Alt+Q"、"Ctrl+Shift+1" 这类组合键。存盘后重启生效。

注意：单字母键是全局占用的，游戏里也用同样键位会冲突，改成带修饰键的写法。

托盘

右下角托盘有喵喵图标：左键 = 显示/隐藏；右键 = 菜单（页面、识图、计算器、快捷键说明、退出）。

9. 反向推断敌方配置

在 deck 里展开「反向推断敌方配置」，根据作战数据反推对方个体值、性格、技能威力、HP。

怎么填

敌方 HP%+我方技能+实测伤害+敌方技能+受到的伤害+我方 HP%→反推配置

输出什么

项说明
我方 HP当前 / 上限 + 百分比
敌方 HP按反推个体值重算的上限 + 当前
六项个体值HP / 物攻 / 魔攻 / 物防 / 魔防 / 速度
性格25 种性格里误差最小的那个
误差两组伤害各自的最小误差点数

原理

按 60 级 / 5 星，遍历 25 种性格 × 0~31 个体值，用 37/41 常数 + 本系 1.25 + 属性克制
算出预期伤害，和你填的实测伤害对比，取误差最小的组合。

这是启发式反推，不是唯一解
· 一次伤害只能约束一项防御或攻击，其他个体值仍按 10 显示
· 没算特性、印记、连击、减伤等局内修正
· 至少填一组「技能 + 实测伤害」才有意义

面板可以上下滑动，右侧金色细条是滚动条。

10. 存档与分享

存档本局 —— 同一台设备保存多局，随时切换

导出记录 —— 双方配置 + 全部回合历史存成 json

导出表格 —— 导出 Markdown 对战表，方便贴群里

导入记录 —— 读回 json，换设备也能复盘

分享 —— 生成带参数的链接，别人打开就是你这套配置

数据存在浏览器本地（localStorage），换设备或清缓存会丢。重要记录请先导出。

11. 常见问题

伤害比游戏里低

先看技能卡有没有标黄「特性未计入」。没有的话做第 4 步校准。少数机制型特性确实算不了，会在卡片上提示。

找不到某只精灵

用名字搜索；新赛季的勾「只看 S5·新增」。确认查的是合并后的 665 只，不是原始数据。

头像空白

少数精灵没有立绘，会用属性色块兜底，不影响计算。

悬浮窗挡住了游戏 / 点不到游戏

安卓：默认只显示底部一条操作栏。如果 deck 展开了，按「收起」或「页面」。
电脑：按 F1 整个隐藏；或按 Esc 收起 deck。

按了按钮没反应

安卓：先确认是不是装的最新版（重装后悬浮窗权限会重置，要重新授予）。
电脑：按钮被游戏独占捕获时，用全局快捷键（Q W E R 等），快捷键不依赖窗口焦点。

电脑版双击没反应

确认解压完整（不要直接在压缩包里双击）。如果启动即退出，检查是否有杀毒软件拦截，或看启动日志里的「快捷键注册失败」提示。

识图读不到图 / 读到旧图

系统相册里最新一张才会被识别。截完等 1–2 秒再点「识」。

手机横屏 HUD 被裁

浏览器方式加 &compact=1；APK 悬浮窗会自动适配。

换设备数据没了

数据在本地。先「导出记录」，新设备上「导入记录」。

12. 数据说明

当前数据量

  • 精灵 665 只
  • 技能 852 条（含 bwiki 新增 21 条）
  • 可学技能表 697 只
  • 立绘 737 张
  • 属性 18 种

来源

  • 属性 / 种族值 / 特性 / 血脉 / 进化链：官方数据文件
  • 状态与印记：官方 buff 表（含触发时机、叠加上限、免疫）
  • 伤害公式：官方引擎结构
  • 新精灵新技能：bwiki
已知局限
· 约 10 条「入场/离场/击败/每使用 N 次」类特性算不了，卡片会标黄
· 双打只做了目标与群体技能口径，没做双速先手与集火顺序
· 进化之力没有校验「首领血脉」前置，只做提示
· 反推面板是启发式，不是唯一解
· 各人数据存在自己浏览器里，不上传，互不影响
